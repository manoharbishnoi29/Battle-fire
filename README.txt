BATTLE FIRE
===========

GAME ENGINE:
Godot 4.x

GAME TYPE:
3D Arena Prototype

CURRENT FEATURES:
1. 3D Ground
2. Third Person Player
3. Follow Camera
4. Buildings
5. Trees
6. Water
7. Jump
8. Basic HUD

CONTROLS:
Arrow Keys = Move
Space = Jump
Mouse Click = Capture Mouse
ESC = Release Mouse

FUTURE DEVELOPMENT:
1. Mobile Joystick
2. Character Models
3. Character Animations
4. Island Map Improvements
5. Lobby
6. Multiplayer
7. 50 Player Match Target
8. APK Export

IMPORTANT:
This is a starter prototype.
It is not a finished online multiplayer game.
